BUG NA CIDADE METROPIXEL
Você é o engenheiro-chefe chamado para reconstruir a rede inteligente de metrô.

1. O sistema apagou conexões

Estações ficaram isoladas e passageiros começaram a acumular tickets sem rota. Cada estação representa um elemento do conjunto A.

2. Trilhos viram pares de R

Ao traçar linhas entre estações, você visualiza pares da relação R. O quadro lateral traduz o mapa para notação matemática.

3. As leis aparecem durante o jogo

Reflexividade, simetria, transitividade e equivalência são desbloqueadas como conceitos quando a rede construída permite mostrar essas ideias.

Metáfora matemática

Estação = elemento de A.
Linha = conexão didática entre elementos.
Par ordenado = registro no quadro R.
Baldeação = visual para discutir transitividade.

CENTRAL DE TREINAMENTO METROPIXEL
Explicação rápida para apresentar os conceitos antes ou depois da partida.
O QUE É RELAÇÃO
R ⊆ A×A
Uma relação é um conjunto de pares ordenados formados com elementos de A.
Ex: A = {A, B, C}
R = {(A,B), (B,C)}
REFLEXIVA
∀a ∈ A: (a,a) ∈ R
Todo elemento se relaciona consigo mesmo.
No metrô: cada estação tem um atendimento para ela mesma. A→A.
SIMÉTRICA
(a,b) ∈ R → (b,a) ∈ R
Se A se conecta com B, B também se conecta com A.
No metrô: linha de ida e volta. A→B e B→A.
TRANSITIVA
(a,b) ∈ R ∧ (b,c) ∈ R → (a,c) ∈ R
Se A se relaciona com B e B com C, A precisa se relacionar com C.
No jogo, a baldeação ajuda a visualizar; matematicamente o par (A,C) precisa estar em R.
EQUIVALÊNCIA
Reflexiva + Simétrica + Transitiva
A relação satisfaz as três propriedades ao mesmo tempo.
Rede completa e consistente: todos os requisitos aparecem no quadro da relação.
